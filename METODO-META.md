# Método da meta de proteína

## Regra principal

A meta diária é **definida pelo profissional** e digitada no primeiro uso do app. O app não altera essa meta.

## Estimativa provisória (quando o aluno ainda não tem meta)

Aprovada pelo responsável técnico em 28/10/2026. É estimativa educativa, não prescrição.

`meta = peso usado (kg) × fator (g/kg/dia)`, arredondada para múltiplo de 5 g.

| Objetivo | Faixa (g/kg/dia) | Fator por rotina: sedentário / pouco ativo / moderado / muito ativo | Referência |
|---|---|---|---|
| Emagrecimento | 1,2–1,6 | 1,2 / 1,3 / 1,4 / 1,6 | Leidy et al., Am J Clin Nutr, 2015 |
| Perder gordura e ganhar massa | 1,6–2,0 | 1,6 / 1,6 / 1,8 / 2,0 | Leidy 2015; Morton et al., Br J Sports Med, 2018 |
| Ganho de massa | 1,4–2,0 | 1,4 / 1,5 / 1,6 / 1,8 | ISSN (Jäger et al., 2017); Morton 2018 |
| Manutenção | 0,8–1,4 | 0,8 / 1,0 / 1,2 / 1,4 | DRI/IOM; ISSN 2017 |
| Envelhecimento saudável | 1,0–1,2 | 1,0 / 1,1 / 1,2 / 1,2 | PROT-AGE (Bauer et al., JAMDA, 2013) |

Os pontos intermediários dentro de cada faixa são decisão de projeto, sujeita a revisão profissional.

## Salvaguardas

- **Peso usado:** peso atual. Com IMC ≥ 30, usa o peso equivalente ao IMC 25.
- **65 anos ou mais:** fator mínimo de 1,0 g/kg/dia.
- **Sem estimativa automática** (o app pede a meta do profissional): menor de 18 anos, IMC abaixo de 18,5, ou resposta "sim" para doença renal, gestação/amamentação, orientação para controlar proteína ou outra condição de saúde que envolva a alimentação.
- Mudança de perfil nunca altera a meta sozinha: o app mostra a diferença e pede confirmação.
- O histórico compara cada dia com a meta que valia naquele dia.
